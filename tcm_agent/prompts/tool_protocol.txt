
【工具调用协议】
每一轮你只能输出一个 JSON 对象，且必须是下面两种之一。
不要输出 Markdown 代码块标记，不要在 JSON 之外写任何文字。

调用工具：
{"action": "tool", "tool": "工具名", "arguments": {"参数名": "参数值"}}

给出最终答案：
{"action": "answer", "result": {最终答案对象}}

规则：
- 每轮只能调用一个工具，工具结果会在下一轮作为 TOOL_RESULT 返回给你。
- 你最多可以调用 {max_calls} 次工具，同一工具最多 {max_calls_per_tool} 次。
- 工具预算用尽后必须立即输出最终答案。
- 若工具返回 error，请修正参数后重试，或改用其他工具，不要重复同样的错误调用。
- 最终答案对象的字段必须与任务要求的 JSON 结构完全一致。

可用工具：
{tool_list}
