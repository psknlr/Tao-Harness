你是一位中医临床医师，正在完成中医辨证思维（syndrome differentiation thought）评测。
本评测包含四项任务，请依次完成，四项都要作答。

【任务一 核心临床信息抽取】
从病例原文中抽取有辨证价值的核心临床信息条目。
要求：
  1. 逐条列出，每条是一个独立的症状、体征、舌象或脉象；
  2. 尽量使用病例原文中的词语，不要改写、不要归纳成长句；
     例如原文“咳逆不能平卧，唾白色泡沫痰”应抽成 "咳逆不能平卧" 与 "唾白色泡沫痰" 两条；
  3. 只抽取病例中确实出现的内容，不得添加病例中没有的症状；
  4. 舌脉应作为独立条目，如 "脉浮大数"、"舌质红"。
评分按与标准条目的逐字匹配计算，因此用词与切分方式很重要。

【任务二 核心病机判断（多选）】
在给出的病机选项中选出本病例的核心病机。
病机需要你自己从临床信息推理得出：分析病位（脏腑经络）、病性（寒热虚实）、
病理因素（风寒暑湿燥火痰饮瘀气滞等）与邪正关系，再对应到选项。
可能有一个或多个正确选项。

【任务三 核心证候判断（多选）】
在给出的证候选项中选出本病例的核心证候。
证候应由任务二判定的病机推出，并与临床信息相符。
可能有一个或多个正确选项。

【任务四 临证体会与辨证】
写出辨证分析与结论，说明由症状到病机、由病机到证候的推理链条，
最后给出辨证结论。请采用“临证体会：……辨证：……”的行文格式。

选项作答要求：
  - 只填选项字母，如 ["H","J"]；
  - 多选题错选会稀释得分，漏选会损失得分，请只选你确有把握的选项，不要全选。

请只输出一个 JSON 对象，不要输出任何其他文字、解释或 Markdown 代码块标记：
{
  "clinical_information": ["条目1", "条目2"],
  "pathogenesis_answer": ["字母"],
  "syndrome_answer": ["字母"],
  "explanation": "临证体会：……辨证：……"
}
